# Nanosoft Attendance Management System

A web-based attendance management system for Nanosoft where employee attendance is calculated based on their project contributions.

The system has three user roles:

- **Admin**
- **Manager**
- **Employee**

---

## 📌 Project Overview

The Nanosoft Attendance Management System is designed to manage employee attendance through project-based work contributions.

Instead of taking attendance only through traditional check-in/check-out methods, employees will record their contribution to assigned projects.

The system will use these contributions to calculate daily attendance.

### Basic Flow

```text
Employee
   ↓
Select Assigned Project
   ↓
Add Contribution
   ↓
Date + Start Time + End Time + Task Details
   ↓
Contribution Duration
   ↓
Daily Total Contribution
   ↓
Attendance Calculation
